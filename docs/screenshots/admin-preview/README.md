# Admin article preview screenshots

The article preview on the admin dashboard (`/admin/dashboard`, click an
article title). Captured at 1280px wide from a local build running against a
throwaway database seeded with sample articles; none of it is production data.

| File | Shows |
| --- | --- |
| `01-preview-header-light.png` | The preview header with the article id ("Article Preview #1"), above the hero image and title. |
| `02-scouts-take-light.png` | Scout's Take rendered below the content, as on the public page, followed by the admin-only Critic Report. |
| `03-not-enriched-light.png` | An article enrichment has not reached yet: the "No image yet" and "No Scout's Take yet" notes. |
| `04-revision-thread-light.png` | The Revision history conversation: an admin request answered by Revision 2 (critic score, word count, failed checks, revised article expanded, previous version collapsed), then an emailed request whose rewrite failed once and is being retried. |
| `05-revision-thread-dark.png` | The same conversation in the dark theme. |
