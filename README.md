# MilesAhead

A self-hosted content aggregation platform that scans miles and points websites, generates articles using AI, and publishes them after admin review. Includes 52 curated credit card reference pages with the Scout persona.

**Live:** [milesahead.kumaranik.com](https://milesahead.kumaranik.com)

## Features

- **Automated Scanning** — RSS scraping of 6+ miles/points sources every 2-4 hours
- **AI Pipeline** — Dual-model: Nemotron generates articles, Llama 70B verifies accuracy
- **Image Pipeline** — 4-source search (Unsplash, Pexels, Openverse, Wikimedia) with vision model scoring
- **Reference Pages** — 52 credit card guides across 6 categories with Scout persona verdicts
- **Card Comparison** — Side-by-side comparison of 2-3 cards (earning rates, credits, benefits, protections, transfer partners)
- **Card Infographics** — Designed infographics on card pages: a teaser in the card-art slot opens the full image in an in-page viewer
- **Article Tags** — AI-generated tags from 8 categories with tag filter pills on homepage
- **Admin Dashboard** — Review queue with approve/reject/revise workflow, newsletter admin workflow
- **Magazine-Style Site** — Dark/light mode, two-column articles, category filters, RSS feed
- **Branding** — The mountain mark, misty header, home hero and footer band from the card infographics, as SVG in `static/img/brand/` (ridges generated by `scripts/brand/gen_band.py`); PNG copies for email, the favicon and the default share image come from `scripts/brand-images.sh`
- **Newsletter** — Weekly newspaper-style email with Scout's Pick, Card of the Week, tag-grouped articles
- **Zero Cost** — OCI free-tier compute, NVIDIA API, SQLite

## Tech Stack

- **Language:** Go 1.26+
- **Database:** SQLite (WAL mode)
- **AI:** NVIDIA API (Nemotron, Llama 70B, Llama Vision)
- **Deployment:** OCI ARM VM, Caddy, systemd, GitHub Actions CI/CD
- **Observability:** Grafana Cloud (Prometheus + Loki via Alloy)

## Quick Start

```bash
git clone https://github.com/anik-apps/milesahead.git
cd milesahead
cp config.example.yaml config.yaml
# Edit config.yaml with your NVIDIA API key and admin password
go build -o milesahead ./cmd/milesahead
./milesahead
```

Seed credit card reference pages and structured comparison data:
```bash
go run ./cmd/seed-cards
go run ./cmd/seed-structured
```

### Choosing AI models

Providers retire models without warning, and the catalogue endpoint is not a
liveness signal — of 81 models it advertised, only 9 answered. Verify any change
to `generator_model`, `fallback_generator_model` or `critic_model` by measuring
it against real source material rather than trusting the listing:

```bash
# Which models answer at all, and do they honour the critic's JSON contract?
go run ./cmd/ab-models -critic-candidates "model-a,model-b" -generators model-a

# Score candidate generators on real clusters, using one fixed critic
go run ./cmd/ab-models -topics 5 -generators "model-a,model-b" -critic model-c

# Dump whole articles for human review, then render them side by side
go run ./cmd/ab-models -full -generators model-a -critic model-c -out a.json
python3 scripts/render_article_review.py a.json b.json > compare.html
```

The app also runs a startup preflight against every configured model and logs
`ERROR` if nothing can generate, so a retired model surfaces at boot rather than
as articles quietly never appearing.

### Enrichment

Scout's Take, key details, tags and the article image are **not** produced during
article generation. They run as a background reconciliation pass
(`internal/enrich`) on `enrichment_interval`, against `enrichment_model` — a
separate chain from the critic, so a degraded critic backend cannot take them
down with it.

This matters because inline they were best-effort: a single slow response
permanently cost the article a field, and for two and a half months roughly a
quarter of articles published with one missing. Reconciled, a miss is simply
picked up next pass. `enrichment_max_attempts` bounds how long an article keeps
being retried, and `milesahead_articles_degraded` reports how many are still
missing something.
